SUNNY HOP — STANDALONE EDITION

PLAY ON A COMPUTER
1. Extract this ZIP if you downloaded the package.
2. Double-click index.html, or open it with Chrome, Edge, Firefox or Safari.
3. Click LET'S HOP. No account, sign-in, installation or internet connection is required.

CONTROLS
Move: A / D or Left / Right arrows
Jump: Space, W or Up arrow
Pause: Escape or the pause button
Restart: the circular-arrow button
Sound: use SOUND to enable/mute audio; separate music and sound-effect sliders appear on the menu and when paused.
Phone/tablet: use the on-screen controls. For mobile sharing, hosting the file as a public static website is usually more convenient than opening an HTML attachment.

WHAT'S INCLUDED
The approved college-campus background, player character, round favicon coins, platforms and checkpoints, menu and gameplay music, jump/end cues, and the corrected short bell-sparkle coin sound. All artwork and audio are embedded in index.html. The file is the complete game.

SHARE WITHOUT ACCOUNTS
Send someone the index.html file or this ZIP. They do not need a Higgsfield account.
For a public link, upload index.html to your own static website host. It runs as a static file, without a backend, API keys, account system or database. Make sure that host's password protection/access restrictions are disabled if you want anonymous play. This package does not create a new hosted URL.

SAVES AND PRIVACY
Run progress, best coin score, mute preference, and music/effects volumes are stored only in the player's browser when local storage is available. Reloading offers the saved run. Restart clears the current run but retains audio preferences and best score.
File-based storage behavior differs by browser. Private browsing, disabled storage, moving/renaming the HTML file, changing its hosted URL, or clearing browser data may reset saves. The game remains playable if saving is blocked.
There is no account, analytics, advertising, network connection or cloud save. Progress from the existing hosted game is not imported automatically.

BROWSER NOTES
Audio starts only after a click/tap/key press because browsers restrict autoplay. An attachment preview may not run HTML: download the file and open it in an actual browser. Modern desktop browsers are recommended for opening the file directly. Fullscreen availability depends on the browser.
